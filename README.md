## 实践项目

### 学生手册本地问答工具

学生手册内容较多，查找具体规定不太方便。为此，我提出搭建一个可以直接提问、查看原文依据的本地知识库。

目前实现的功能：

- 用自然语言查询学生手册中的规定
- 查看回答对应的章节、条款和原文
- 在个人电脑上运行，无需调用付费 API
- 对手册未涉及的问题提示资料不足

**我的参与**

提出使用需求，提供学校手册，参与试用并反馈使用中遇到的问题。

**AI 的参与**

程序编写、模型部署、文档解析和技术验证主要由 Codex 完成。这是一次 AI 辅助实践，我仍在学习相关技术原理。

**目前的局限**

回答依据所导入的手册版本，不能自动反映最新政策；模型回答可能出错，需要结合引用原文核对。
